# DroperOG Grabber — دانلود فایل‌های تلگرام 📥

ماژول **دانلود گروهی فایل** که کنار `droperog.py` و `hunter.py` می‌نشیند.

| | droperog.py / hunter.py | grabber.py (این) |
|---|---|---|
| نوع اتصال | Bot API (فقط ارسال پیام) | MTProto با **اکانت خودت** |
| دسترسی | فقط چت‌هایی که بات آن‌جاست | همه‌ی چت/گروه/کانال‌های پریوایت که عضوی |
| سقف فایل | ۲۰MB (محدودیت بات) | ۲GB (با پرمیوم ۴GB) |
| کار | خبر دادن ایردراپ | دانلود فایل‌ها |

---

## ۱) گرفتن کلید (یک‌بار برای همیشه)

برو به **https://my.telegram.org** ← `API development tools` ← یک اپ بساز و دو مقدار بگیر.
بعد در `.env` بگذار:

```bash
TG_API_ID=1234567
TG_API_HASH=abcdef0123456789abcdef0123456789
TG_PHONE=+98912XXXXXXX
```

> `TG_PHONE` فقط برای بار اول لازم است (کد ورود). بعد از آن `data/grabber.session` ساخته می‌شود.

## ۲) نصب

```bash
pip install -r requirements.txt      # telethon
python grabber.py --login            # بار اول: کد ورود + رمز دو مرحله‌ای (اگر داری)
```

## ۳) استفاده

```bash
python grabber.py --list                          # لیست چت‌ها با id و @username
python grabber.py --chat me                       # Saved Messages
python grabber.py --chat @my_channel
python grabber.py --chat @a --chat @b --chat 1234567890
python grabber.py --all                           # همه‌ی دیالوگ‌های اکانت
```

### گزینه‌ها

| گزینه | کار |
|---|---|
| `--chat SPEC` | قابل تکرار؛ `me` یا `@username` یا آیدی عددی |
| `--all` | همه‌ی دیالوگ‌ها |
| `--types LIST` | `photo,video,video_note,document,audio,voice,gif,sticker` یا `all` <br> پیش‌فرض: همه جز `sticker` |
| `--min-size` / `--max-size` | فیلتر حجم مثل `5MB` یا `1.5GB` |
| `--since` / `--until` | بازه‌ی تاریخ `YYYY-MM-DD` (هر دو سر شامل) |
| `--limit N` | حداکثر تعداد پیام هر چت |
| `--out DIR` | پوشه‌ی مقصد (پیش‌فرض `downloads/`) |
| `--sleep SEC` | فاصله‌ی بین فایل‌ها (پیش‌فرض ۱ ثانیه — مهربان با API) |
| `--full` | نادیده گرفتن حافظه و اسکن کامل از اول |
| `--thumbs` | تصویر بندانگشتی هم ذخیره شود |
| `--dry-run` | فقط گزارش؛ هیچ چیزی دانلود یا ثبت نمی‌شود |

### نمونه‌ها

```bash
# اول ببین چه خبر است (هیچ چیزی دانلود نمی‌شود)
python grabber.py --chat @my_channel --types video --dry-run

# بعد فقط ویدیوهای بالای ۵۰ مگ از یک کانال
python grabber.py --chat @my_channel --types video --min-size 50MB

# همه‌ی فایل‌های ۲۰۲۶ به بعد، همه‌ی چت‌ها، روی درایو D
python grabber.py --all --since 2026-01-01 --out D:\tg
```

## کیفیت فایل‌ها

تلگرام برای هر پیام **یک فایل** نگه می‌دارد و همان را برمی‌گرداند؛ پس این ابزار:

- برای عکس، **بزرگ‌ترین سایز موجود** را می‌گیرد (نه پیش‌نمایش کوچک)
- برای ویدیو و فایل، **فایل اصلی دست‌نخورده** را می‌گیرد (نه نسخه‌ی فشرده‌ی پیش‌نمایش)
- بندانگشتی‌ها را به‌طور پیش‌فرض دانلود **نمی‌کند** (`--thumbs` برای فعال کردن)

اگر فرستنده خودش ویدیو را در کیفیت پایین آپلود کرده باشد، بهترین چیزی که روی سرور
وجود دارد همان است — ابزار نمی‌تواند چیزی بهتر از منبع بسازد.

## ساختار خروجی

```
downloads/
  My Channel_-1001234567890/
    20260201_1024_original_name.mp4
    20260201_1025_photo.jpg
  Ali B_55512345/
    20260203_88_report.pdf
```

نام فایل = `تاریخ_آیدی‌پیام_نام‌اصلی` و کاراکترهای غیرمجاز ویندوز پاک می‌شوند.

## اجرای دوباره (مهم‌ترین ویژگی)

هر اجرا **حافظه دارد**:

- `data/grabber_state.json` ← آخرین آیدی پیام هر چت + فهرست فایل‌های گرفته‌شده
- اجرای بعدی فقط **پیام‌های تازه‌تر** را می‌خواند و فایل‌های موجود را **پرش** می‌کند
- پس می‌توانی همین دستور را هر شب (یا در Task Scheduler) تکرار کنی و فقط جدیدها بیایند

برای اسکن کامل از صفر: `--full` (فایل‌های موجود باز هم پرش می‌شوند).

## محدودیت‌ها و نکات

- **فقط چیزی که اکانتت می‌بیند.** اگر عضو کانال نباشی، چیزی دانلود نمی‌شود
  (`ChannelPrivateError` در لاگ می‌آید و پرش می‌شود).
- **FloodWait:** اگر زیادی سریع بروی، تلگرام قفل می‌گذارد؛ ابزار خودش صبر می‌کند
  ولی `--sleep 2` یا بیشتر عاقلانه‌تر است.
- **`data/grabber.session` = کلید کامل اکانتت.** این فایل را به هیچ‌کس نده و
  کامیت نکن (در `.gitignore` هست).
- سقف دانلود ۲GB (پرمیوم ۴GB) در هر فایل است.
- ادب و قانون: فایل‌های دیگران را بدون اجازه بازنشر نکن و به شرایط استفاده‌ی
  تلگرام احترام بگذار. این ابزار برای **آرشیو کردن محتوای خودت** است.

## چطور تست کنم؟ (نردبان تست)

### قبل از هر چیز — یک دستور، یک حکم

```bash
python grabber.py --selftest
```

بدون اکانت و بدون اینترنت ۸ چیز را چک می‌کند (پایتون، telethon، اعتبارنامه، سشن،
نوشتن `state`، پوشه‌ی خروجی، امن‌سازی نام فایل، و کل مسیر دانلود) و آخرش صریح
می‌گوید قدم بعدی چیست. گزارش در `data/grabber_selftest.txt` هم می‌نشیند.

کد خروجی: `0` = همه‌چیز آماده (حتی اعتبارنامه) ، `1` = نصب سالم ولی یک قدم مانده.

> اگر `python grabber.py` می‌زنی و خطای `No such file or directory` می‌گیری،
> یعنی فایل در پوشه‌ی جاری نیست. یا `cd` کن به پوشه‌ی پروژه، یا فایل `grabber.py`
> را کنار `droperog.py` کپی کن.

### سطح ۰ — همین الان، بدون اکانت و بدون اینترنت

```bash
python grabber.py --demo
```

یک چت ساختگی با عکس/ویدیو/PDF/ویس می‌سازد، **کل مسیر واقعی دانلود** را اجرا می‌کند
و بعد یک بار دیگر اجرا می‌کند تا ببینی چطور همه را پرش می‌کند. خروجی موقت در
`downloads/_demo` می‌نشیند (هر وقت خواستی پاکش کن) و `state` واقعی پروژه دست نمی‌خورد.

### سطح ۱ — تست‌های خودکار

```bash
python -m pytest tests/ -q
```

بدون اکانت و اینترنت: کلاینت تلگرام شبیه‌سازی شده اما فایل‌ها روی دیسک واقعی
نوشته می‌شوند، پس منطق نام‌گذاری/پرش/state واقعاً تست می‌شود.

### سطح ۲ — با اکانت خودت، بی‌ریسک

```bash
python grabber.py --login          # فقط لاگین و نمایش خودت، هیچ دانلودی
python grabber.py --list           # مطمئن شو چت‌ها را درست می‌بیند
python grabber.py --chat @x --limit 20 --dry-run   # بگو چه‌چیزی می‌خواهد بردارد
```

### سطح ۳ — دانلود واقعی و کوچک

```bash
python grabber.py --chat me --limit 5 --sleep 2 --out ./downloads
```

همین دستور را بار دوم بزن: باید همان ۵ فایل را «پرش» کند.

> `--login` سشن را در `data/grabber.session` می‌سازد و بار بعدی دیگر کد نمی‌خواهد.
