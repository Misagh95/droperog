# DroperOG Hunter — شکار زودهنگام 🎯

ماژول **شکار زودهنگام** که کنار `droperog.py` اجرا میشه. تفاوتش رو بدون:

| | droperog.py (خودت) | hunter.py (این) |
|---|---|---|
| منابع | لیستهای عمومی (AlphaDrops + CryptoRank + DropJet) | منابع قبل از لیستها |
| زمان رسیدن | دیر (وقتی همه دیدن) | زود (قبل از شلوغ شدن) |
| سؤال | «توی لیستها چه خبره؟» | «چی تازه ظاهر شده؟» |

---

## اجرای محلی (اختیاری — فقط برای تست)

```bash
pip install requests
python hunter.py                     # فقط گزارش
python hunter.py --telegram --dry-run  # پیشنمایش پیام تلگرام بدون ارسال
```

هر اجرا (بدون نیاز به هیچ API-کی):
1. **تستنتهای فعال** را از dropjet.co میگیرد 🟣
2. **خبرهای فاندینگ ۳ روز اخیر** را از Google News + CoinDesk/TheBlock میخواند 💰 (پروژهای که تازه پول جذب کرده = ایردراپ آینده)
3. **ریپوهای جدید گیتهاب** (۷ روز اخیر) با موضوع ایردراپ را میبیند 🐙 (سیگنال خیلی زودرس)

## ⭐ راهاندازی خودکار با GitHub Actions (پیشنهادی — بدون نیاز به سیستم خودت)

اکشن هر ۶ ساعت خودش اسکن میکند، نتیجه را تمیز به **بات تلگرام** میفرستد و state را در خود گیتهاب ذخیره میکند (تا دفعه بعد فقط «مورد جدید» را بگوید).

### قدم ۱ — اضافه کردن فایلها به ریپو

این ۳ فایل را به ریپوی `droperog` اضافه کن (از طریق «Add file» در گیتهاب یا گیت):
- `hunter.py`
- `README_HUNTER.md` (همین فایل)
- `.github/workflows/hunter-scan.yml` ← **فایل workflow آماده است؛ فقط مسیرش درست باشد**: `.github/workflows/hunter-scan.yml`

### قدم ۲ — تنظیم سکرتها (اگر قبلاً برای scan.yml تنظیم کردهای، کاری نکن)

ریپو ← **Settings** ← **Secrets and variables** ← **Actions** ← **New repository secret**:

| نام | مقدار |
|---|---|
| `BOT_TOKEN` | توکن بات تلگرامت (از @BotFather) |
| `CHAT_ID` | آیدی عددی چت/کانالی که پیامها به آن میرود |

> اگر قبلاً برای `scan.yml` اینها را ساخته باشی، همانها استفاده میشوند — hunter هر دو نام (`BOT_TOKEN`/`TELEGRAM_BOT_TOKEN`) را میخواند.

### قدم ۳ — فعال شدن

بعد از push شدن `hunter-scan.yml`، اکشن خودش اجرا میشود:
- هر **۶ ساعت** (ساعت ۰۰:۳۰، ۰۶:۳۰، ۱۲:۳۰، ۱۸:۳۰ به وقت تهران) — سیکل از تنظیمات `cron` در فایل
- یا **دستی:** تب **Actions** ← **Hunter Scan (Early Detection)** ← **Run workflow**

### قدم ۴ — تنظیم یادآوری کانال (اختیاری)

پیام تلگرام به `CHAT_ID` میرود؛ اگر میخواهی به کانال عمومی «DigitalDreams» هم برود، CHAT_ID کانال را تنظیم کن (کانال باید بات را ادمین کند).

## راهنمای بارانداز (این بخش کار خودته)

گزارش فقط **مواد اولیه** است؛ تصمیم نهایی با تو:

### 🟣 تستنت — امتیاز به تازگی:
- **هفته اول باز شدن = طلا** (کمترین رقابت)
- تستنت ۳ ماهه = فقط اگر دلیل خاصی داری
- به صفحه پروژه برو: فاندینگ اعلام شده؟ تیم معلومه؟ فقط تسک اجتماعی داره یا فعالیت آنچین هم داره؟

### 💰 خبر فاندینگ — قانون طلایی:
- فاندینگ ≠ ایردراپ، ولی **هر پروژهای که پول جذب کرده، به توکن نیاز داره** → توی ۶-۱۲ ماه آینده کاندیده
- پروژه رو پیدا کن → ببین تستنت/پوینت باز کرده → اگه نه، ولش کن و برای بعد رصدش کن
- اسکمهای «پریسیل» (بدون فاندینگ معتبر + وعده ۵۰۰x) رو فیلتر کن

### 🐙 گیتهاب — بیشتر نویزه:
- ریپوهای شخصی و دموها زیادن؛ فقط اونهایی که به یه تستنت/پروژه واقعی اشاره میکنن ارزش بررسی دارن

### ❓ نامشخص:
- یعنی پارسر نتونست دستهبندی کنه — خودت تصمیم بگیر

## توسعه برای آینده

- افزودن منبع: فید RSS دیگری را به `SECONDARY_FEEDS` اضافه کن
- افزودن کوئری گوگلنیوز: به `FUNDING_QUERIES` اضافه کن
- تغییر سیکل: `cron` را در `hunter-scan.yml` عوض کن (مثلاً `0 */3 * * *` = هر ۳ ساعت)
